## Notable confirmed bugs / footguns (not in shortlist but real)

- **`results_test/` not in `.gitignore`** (ENG-08 / SEC-13) — only `results/` is. Append `results_test/` (or `results*/` glob) to `.gitignore`.
- **launch.sh `eval "$NF_CMD"`** (SEC-01 / SEC-17) — drop the eval; pass args as array. Low blast radius today, but it's the only `eval` in the tree.
- **Hardcoded `/dfs7/swaruplab/lesolano/ref/...` paths** (SEC-10/11/14) — public repo references one user's home tree as the only working path layout. Reproducibility bomb for any collaborator.
- **JASPAR2022_core_nonredundant.jaspar** (MIS-09) is taxon-agnostic — wrong-species runs scan against all motifs. Use `JASPAR2022_core_vertebrates.jaspar` filtered by `--tax_group`, or pre-filter by species.
- **Tier-B SHI processes accept globbed `path "diff/*"` with no filename pattern enforcement** (ENG-19) — stale CSV from a prior comparison label silently consumed.
- **No tests/, no CI, no smoke-test entry** (ENG-20) — refactors run blind against multi-hour live-data feedback loops.
